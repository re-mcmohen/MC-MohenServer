# Mohen Server · 我的世界公益生存服

> 不忘初心，方得始终。

从 2021 年 8 月 15 日出发，Mohen Server 希望给热爱 Minecraft 的玩家留下一处可以安心建造、自在探索、和朋友慢慢养老的小天地。

## 第九周目，等你一起开拓

- **服务器版本：26.2**
- **公益生存插件服**：不设置任何充值通道，公平游玩，无神权。
- **Java 跨版本支持**：通过 ViaVersion，让不同版本的玩家相聚。
- **基岩版互通**：通过 Geyser，欢迎基岩版玩家一起冒险。
- **尽可能保留原版特性**：刷线、刷沙、TNT 复制等，让生存与生电创造都有发挥空间。
- **安心建设**：每日自动备份，配合回档插件，守护大家的建筑与劳动成果。

无论你喜欢搭一座温馨的小屋、研究一套红石机器，还是和朋友出门探险，这里都欢迎你。让一个人的生存，变成一群人的故事。
